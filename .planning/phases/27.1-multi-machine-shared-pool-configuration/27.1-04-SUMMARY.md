# Phase 27.1 Plan 04: Safe Shared-Pool Git Coordination Summary

**Consent-gated fast-forward pool pulls and explicit Tome-owned Git publication that leave unrelated worktree and index state untouched.**

## Accomplishments

- Added local `git_sync` one-run override parsing, settings-only consent bootstrap, create-new PID/timestamp lock, sanitized Git commands, porcelain-v2 preflight, and fast-forward-only pull.
- Loaded the selected effective pool/profile exactly once after a consented pull, with integration coverage proving a pulled profile changes the same sync invocation.
- Replaced the sync-wide `git add -A` publication route with deterministic changed owned-path staging for library, pool policy, lockfile, and committed profiles.
- Blocked staged, unmerged, behind/diverged, merge, and rebase repository state without index repair; noninteractive `ask` remains local-only and failed pushes retain the local commit.

**1. [Rule 1 - Bug] Canonicalized repository containment before publication**
- **Found during:** Task 2 integration verification.
- **Issue:** macOS may report the same temporary worktree through `/var` and `/private/var`, causing a lexical owned-path containment check to reject an in-worktree library.
- **Fix:** Canonicalized both repository root and owned paths before deriving relative pathspecs; true out-of-worktree paths now warn and continue local-only.
- **Files modified:** `crates/tome/src/repo_sync.rs`
- **Commit:** `5ce8c64`

**2. [Rule 1 - Regression] Restored explicit legacy-machine sync routing**
- **Found during:** Full CI verification.
- **Issue:** Routing every `sync` invocation through selected-profile Git bootstrap rejected intentional `--machine` compatibility fixtures before their established validation paths.
- **Fix:** Applied new Git coordination only to selected-profile syncs, retained the legacy route, and removed the old automatic backup pull globally.
- **Files modified:** `crates/tome/src/lib.rs`, `crates/tome/src/backup.rs`
