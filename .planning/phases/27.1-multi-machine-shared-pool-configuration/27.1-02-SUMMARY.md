## Decisions Made

- Recovery determines a complete new layout solely from all journaled target bytes, validates it, then retires legacy preferences; partial activation restores the original legacy bytes.
- Migration applies supported legacy path overrides before rendering the profile, preserving the deprecated override syntax only in the backup.
